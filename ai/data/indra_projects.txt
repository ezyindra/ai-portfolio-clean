- TypeScript
- Vite
- Tailwind CSS
- Framer Motion

- TypeScript-based state handling.
- Animated layouts and transitions using Framer Motion.
- Tailwind-driven responsive design.
- Dual Light/Dark theme.

- I also learned that making something "work" is different from making it feel properly designed and complete.

## Agentic Deep Researcher

### What it is
- Agentic Deep Researcher is an autonomous AI research system currently in progress.
- It is designed to plan research, search the web, scrape information, create embeddings, retrieve relevant information, and synthesize structured research reports.

### Tech Stack
- Python
- LangChain
- LangGraph
- OpenAI API
- FAISS
- Tavily API
- BeautifulSoup

### Architecture
- Multi-agent workflows using LangGraph.
- Tool routing and state-based execution.
- Tavily search and BeautifulSoup scraping.
- FAISS vector storage for semantic retrieval.
- RAG pipeline for structured, citation-aware reports.
- Planner → Researcher → Synthesizer workflow.

### Why I created it
- I created it because I am interested in how AI systems can move beyond simple question-and-answer interactions and actually perform multi-step tasks.
- Traditional search requires the user to manually search multiple sources, read them, compare information, and create a final understanding.
- I wanted to experiment with an AI system that could perform more of this research workflow autonomously.
- The project also gives me an opportunity to learn about agentic AI, RAG, vector databases, tool usage, and multi-agent workflows through a real implementation.

### Most interesting part
- The most interesting part is the multi-agent workflow.
- Instead of treating the AI as one single model doing everything, different stages have different responsibilities.
- The Planner decides what needs to be researched, the Researcher gathers relevant information, and the Synthesizer turns the collected information into a structured result.
- The combination of agents, tools, retrieval, and state management makes the system feel more like an actual research workflow.

### Hardest part
- One of the difficult parts is making sure information flows correctly between different stages of the workflow.
- Agentic systems can become complicated because one step depends on the output of another step.
- Retrieval quality, tool selection, state management, and making the final answer reliable all require careful design.
- Another challenge is preventing the system from producing a confident answer when the research itself is incomplete or unreliable.

### Future improvements
- Improve the planning and reasoning workflow.
- Add better source evaluation and research verification.
- Improve retrieval quality and document chunking.
- Add better memory for longer research tasks.
- Improve report formatting and citation handling.
- Explore more specialized agents for fact checking, source comparison, and summarization.
- Experiment with more advanced agentic workflows and autonomous task execution.

## Indra Insights

### What it is
- Indra Insights is an AI-powered article analysis platform.
- It is a full-stack serverless platform designed to scrape and analyze articles through automated pipelines.

### Tech Stack
- React
- TypeScript
- Vite
- Tailwind CSS
- Supabase
- PostgreSQL
- Supabase Auth
- Supabase Edge Functions
- Recharts

### Features
- Automated content extraction.
- AI-driven article analysis.
- Interactive dashboards for credibility, bias, and emotional insights.
- Secure authentication.
- Historical data storage using PostgreSQL.
- Serverless backend functionality using Supabase Edge Functions.

### Project
- https://indra-insights.vercel.app/

### Why I created it
- I created Indra Insights because I was interested in using AI to analyze written content rather than simply generating content.
- Articles can contain different viewpoints, emotional language, and potential bias, so I wanted to experiment with turning an article into structured insights.
- The project allowed me to combine AI, data visualization, backend development, authentication, databases, and modern frontend development in one application.

### Biggest challenge
- One of the biggest challenges was connecting multiple parts of the application into one reliable workflow.
- Article extraction, AI analysis, database storage, authentication, and visualization all have to work together.
- Making the application feel simple to the user while handling a more complicated backend process required careful thinking.

### Biggest learning
- I learned how different technologies can work together to form a complete product rather than just an isolated feature.
- I gained experience with serverless development, Supabase, database-backed applications, authentication, data visualization, and AI-powered processing.
- The project also taught me that presenting AI-generated information clearly is just as important as generating the information itself.---

## 3D Personal Portfolio

### What it is
- A high-performance desktop-first 3D personal portfolio featuring immersive WebGL graphics, interactive animations, and a personalized AI assistant.

### Tech Stack
- Next.js
- React
- TypeScript
- Three.js
- React Three Fiber
- Tailwind CSS
- Framer Motion

### Features
- Real-time 3D scenes.
- Interactive camera controls.
- Smooth UI transitions.
- Responsive layout.
- Optimized asset loading.
- Lazy-loaded 3D assets.
- Component-level code splitting.
- GPU-friendly rendering.
- Interactive AI assistant connected to a personal knowledge base.

### Project
- https://indra-portfolio-xi.vercel.app/

### Why I created it
- I wanted my portfolio to be more than a traditional resume website.
- Since I enjoy both technology and visual creativity, I wanted to combine my software development skills with 3D graphics and interactive design.
- I wanted visitors to experience my projects and personality rather than simply reading a list of skills.
- The portfolio also became an opportunity to experiment with Three.js, React Three Fiber, animations, performance optimization, and AI integration.

### Hardest part
- One of the hardest parts was balancing visual complexity with performance.
- 3D graphics can become expensive for the browser, so the application needs to be designed carefully.
- Optimizing 3D assets, loading behavior, rendering, animations, and normal UI components while keeping the experience smooth required a lot of experimentation.

### Biggest learning
- I learned that an impressive visual experience still needs good engineering underneath it.
- Performance, component structure, loading strategy, and user experience are just as important as the visual design.
- I also learned how powerful it can be to combine different technologies, such as Next.js, React, Three.js, Framer Motion, and AI, into one cohesive application.

### Future improvements
- Continue improving the AI assistant and make it more conversational and personalized.
- Add more personal knowledge and project stories to the assistant.
- Improve the 3D experience and interactions.
- Continue optimizing performance.
- Add more interactive demonstrations of projects.
- Explore additional AI-powered portfolio features.
